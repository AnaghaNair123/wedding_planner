# Anagha & Akshay Wedding Planner

Premium, offline-capable bride-side wedding planning app for the 25 October 2026 Guruvayur wedding.

## Run locally

```bash
npm install
npm run dev
```

## Build and deploy

```bash
npm run build
```

Deploy the generated `dist` folder to Netlify, or connect the repository. `netlify.toml` already supplies the correct build settings and SPA routing.

All planning information is stored automatically in this browser's Local Storage. Use **Settings → Export data** to keep a portable backup.
